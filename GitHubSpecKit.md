Constitution file: Set of non-negotiable principles for your project, like i need next js for a specific version always., i always have to hve test. This file creates automatically, while initializing, but we need to fill it.

Then /specify: Specify the requirement   
![Specify](1.png)  
Creates spec.md file   
Make sure to check Review and Acceptance checklist  in spec.md  



Then /plan: Specify technical requirement.   
![Plan2](6.png)  

See below image; except spec.md, other files are created through /plan  
![Plan2](5.png)  



Then /tasks: Break this down into tasks  
![Tasks](7.png)  
This creates tasks.md file  


Then:  
![Implement](8.png)  
While implement i can change model to use better one    
Create actual artifacts like .js file etc
