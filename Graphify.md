#Graphify

Graphify is a tool that converts a code repo into a knowledge graph, so, AI coding assistants (Guthub Copilot, Claude code, etc) can understand relationships across codebase rather simply searching files.  

Graphify is an open-source tool and AI coding assistant skill that transforms entire software projects—including source code, documentation, PDFs, diagrams, and media—into a queryable, structured knowledge graph. Instead of forcing an AI to scan or "grep" through raw, disconnected files, Graphify maps out how classes, functions, files, and concepts connect to one another.


## What Graphify Does

Instaed of treating your repo as a collection of text files, Graphify creates a graph of:
Classes 
Methods  
APIs  
DB Objects  
Dependencies  
DOmain entities  
Relationship between components  

This allows an AI assistant to query the graoh abd trace relationships across the entire application.  

## Advantages
1. Better AI accuracy  
2. Improved context awareness  
3. Faster RCA  
4. Reduced toke usage: Since the agent queries the graph instead of repeatedly reading large portions of source files, teams observed potential token savings abd reduced context loading requirements.   
5. Better result for large repo
